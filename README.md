# Partial-Graph-Matching-for-Indoor-Robot-Localization

Progetto del corso SEAI — Università di Pisa.

Pipeline GATv2 + Sinkhorn + Hungarian per il partial matching tra grafi architettonici
(A-Graph, da planimetrie BIM) e grafi di scena osservati da un robot (S-Graph), sul task
`ws_room_dropout_noise_inc` del dataset MSD (Modified Swiss Dwellings).
